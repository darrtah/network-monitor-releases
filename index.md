# Network Monitor

Public download and update channel for Network Monitor on Windows.

- [Latest published releases](https://github.com/darrtah/network-monitor-releases/releases)
- [Update manifest](./updates/stable.txt) — available after the first approved release.
- Every executable release contains its SHA-256 digest and the original license and attribution.

**Build source and the Windows CI runner remain private.**

This GitHub Pages site hosts only version metadata. Executable files are distributed as GitHub Releases.
